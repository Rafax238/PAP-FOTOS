### 📝 Sobre o Projeto
O **Cidadão+** é uma plataforma Full-Stack desenhada para modernizar a interação entre munícipes e a administração pública. Através de um sistema centralizado, permite que qualquer cidadão reporte problemas na via pública (buracos, iluminação, resíduos) com localização exata e evidências fotográficas.

> **O objetivo principal:** Reduzir o tempo de resposta das entidades competentes e aumentar a transparência na gestão da cidade.

---

### 🚀 Funcionalidades Chave

* 🔐 **Segurança Avançada:** Autenticação de dois fatores (2FA) para proteção de contas.
* 📧 **Notificações Automáticas:** Integração com **PHPMailer** para confirmação de registo e atualizações de estado.
* 📊 **Dashboard Administrativo:** Painel completo para gestão de utilizadores, freguesias, concelhos e empresas prestadoras de serviço.
* 📱 **Interface Responsiva:** Desenvolvida com foco na usabilidade em dispositivos móveis (Cidadão) e Desktop (Admin).
* 🛠️ **Gestão de Entidades:** CRUD completo para controlo de empresas de manutenção e categorias de ocorrências.

### ⚙️ Como Executar o Projeto

1.  **Clonar o repositório:**
    ```bash
    git clone [https://github.com/Rafax238/PAP-FOTOS.git](https://github.com/Rafax238/PAP-FOTOS.git)
    ```
2.  **Configurar o Servidor:**
    * Mova os arquivos para a pasta `www` ou `htdocs` do seu servidor local (XAMPP/WAMP).
    * Importe o ficheiro `.sql` (se disponível) no PHPMyAdmin.
3.  **Configurar o PHPMailer:**
    * Aceda ao ficheiro de configuração e insira as suas credenciais SMTP para que o envio de emails funcione.
