# 🏙️ Cidadão+ — Gestão Urbana Inteligente
> **Projeto de Aptidão Profissional (PAP) — 2026**

O **Cidadão+** é uma plataforma web inovadora concebida para estreitar a ligação entre os munícipes e a administração pública. A aplicação permite o reporte, monitorização e gestão de ocorrências urbanas em tempo real, promovendo uma cidade mais assistida e eficiente.

---

## 🛠️ Stack Tecnológica
* **Backend:** PHP & MySQL
* **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
* **Segurança:** Autenticação 2FA (Two-Factor Authentication) e PHPMailer para notificações seguras.

## 🚀 Destaque do Projeto
O **Cidadão+** foca-se na eficiência da resposta pública. Através de um backend robusto em **PHP**, garantimos que cada ocorrência seja encaminhada para a entidade competente com evidências fotográficas e localização exata, otimizando o fluxo de trabalho administrativo e a transparência para o cidadão.
