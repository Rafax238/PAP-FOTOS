## 📖 Sobre o Projeto

O **Cidadão+** é uma plataforma colaborativa desenhada para transformar a interação entre munícipes e entidades públicas. Através de uma interface intuitiva, permite que qualquer cidadão atue como um agente de melhoria da sua cidade, reportando incidentes e acompanhando a sua resolução de forma transparente e digital.

### ✨ Diferenciais
* **Transparência:** Acompanhamento do estado da ocorrência em tempo real.
* **Segurança:** Implementação robusta de autenticação de dois fatores (2FA).
* **Eficiência:** Dashboard administrativo para gestão centralizada de dados geográficos e operacionais.

---

## 🛠️ Stack Tecnológica

| Camada | Tecnologia | Utilização |
| :--- | :--- | :--- |
| **Backend** | `PHP 8.x` | Lógica de negócio e API |
| **Base de Dados** | `MySQL` | Armazenamento relacional de dados |
| **Frontend** | `HTML5 / CSS3 / JS` | Interface responsiva e dinâmica |
| **Segurança** | `Bcrypt / 2FA` | Criptografia de senhas e dupla autenticação |
| **E-mail** | `PHPMailer` | Recuperação de conta e envio de tokens |

---

## 🚀 Funcionalidades Principais

* 📍 **Reporte Georreferenciado:** Submissão de ocorrências com imagem e categoria.
* 📊 **Dashboard em Tempo Real:** Visualização de métricas e estados de incidentes.
* 👥 **Gestão de Utilizadores:** Controlo total de permissões por parte do administrador.
* 🛡️ **Segurança Avançada:** Proteção contra ataques comuns e sistema de 2FA obrigatório/opcional.
